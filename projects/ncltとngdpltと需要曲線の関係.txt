名目水準目標と需要曲線の安定化メカニズム

1. 目標の定式化と需要曲線
中央銀行が目指す「名目水準の維持」は、対数乖離（^）を用いると以下のように表されます。
・NCLT（名目総消費水準目標）の目標：^p_t^{H→W} + ^c_t^{H→W} = 0
・NGDPLT（名目GDP水準目標）の目標：^p_t^H + ^y_t^H = 0

一方で、家計の最適化行動から導かれる財市場の需要側の方程式（需要曲線）は、所得の限界効用の対数乖離 ^λ_t^H と外部変数 ^X_t を用いて次のように整理されます。
・CD曲線（消費需要）：^p_t^{H→W} + ^c_t^{H→W} = -^λ_t^H
・YD曲線（生産需要）：^p_t^H + ^y_t^H = ^X_t - ^λ_t^H

定常状態においては ^λ_t^H = 0 および ^X_t = 0 となるため、需要曲線自体が自然に目標値（0）と一致します。

2. ショック発生時の乖離と金融政策の役割
外生的なショック（需要ショックや供給ショック）が発生すると、経済環境の変化を受けて需要曲線の右辺（-^λ_t^H や ^X_t - ^λ_t^H）が変動しようとします。放っておけば、左辺の名目総消費や名目GDPも定常状態から逸脱してしまいます。

ここで中央銀行は、目標を達成するために名目利子率 i_t^H を操作します。前方展開されたオイラー方程式が示す通り、現在の所得の限界効用 ^λ_t^H は、将来にわたる名目利子率 i_t^H の経路によって決定されます。

すなわち、名目水準目標の背後にある一般的なメカニズムは以下のようになります。
(1) ショックによって需要曲線の右辺が動こうとする。
(2) 中央銀行は、目標（^p_t^{H→W} + ^c_t^{H→W} = 0 または ^p_t^H + ^y_t^H = 0）が成立するように i_t^H の経路を調整する。
(3) i_t^H の調整が ^λ_t^H を動かす。
(4) 結果として、変動しようとした需要曲線（CD曲線・YD曲線）の切片が元の位置に引き戻され、名目支出水準が一定に保たれる。

3. aショック（生産性ショック）時における特例と長期的な物価アンカー
aショックが発生した場合、外部変数 ^X_t = 0 となります。このとき、NCLTやNGDPLTの目標を達成し続けるためには、需要曲線を動かさないこと、すなわち所得の限界効用を定常状態に固定する（^λ_t^H = 0）ことが求められます。

λ_t^H を定常状態のまま維持しようとする場合、中央銀行は名目利子率 i_t^H を動かす必要がなくなります（i_t^H は定常状態 i_ss^H に維持される）。

ここで、前方展開された自国コンティンジェント債券に関するオイラー方程式を確認します。
λ_t^H = [ 1 / { (lim_{k→∞} p_{t+k}^{H→W}) * c_ss^{H→W} } ] * E_t [ Π_{j=0}^{∞} β_ss^H (1 + i_{t+j}^H) ]

aショックでは β_t^H は一定（β_ss^H）です。i_t^H が定常状態 i_ss^H に維持されることで右辺の無限乗積が一定になり、かつ λ_t^H も定常状態に維持されるため、方程式の辻褄を合わせるには右辺の分母にある極限値が初期の定常状態の物価水準と完全に一致しなければなりません。
すなわち、以下が数学的に導かれます。
lim_{k→∞} p_{t+k}^{H→W} = p_ss^{H→W}

このように、NCLTやNGDPLTといった「名目水準目標」は、純粋な供給ショックに際して金利を動かさずとも、長期的な物価水準の期待（アンカー）を自動的に初期定常状態に完全に収束させるという強力な自己安定化メカニズムを備えています。
